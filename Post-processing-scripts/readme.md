These Stata do-files turn the model's posterior draws into summary statistics by age and for all ages, by country, region and globe.

`WPP24.dta` is included in this repository so that the do-file can be run without downloading the UN data. It is
an adaptation of the **medium variant** of the UN *World Population Prospects 2024* "Population by single age and sex"
data files (`WPP2024_PopulationBySingleAgeSex_Medium_1950-2023` and
`WPP2024_PopulationBySingleAgeSex_Medium_2024-2100`), available from https://population.un.org/wpp/.
